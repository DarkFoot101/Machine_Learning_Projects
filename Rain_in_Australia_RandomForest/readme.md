# 🌧️ Rain Prediction Model — Rain in Australia Dataset

## 🚀 Overview

This project implements a **machine learning–based rainfall prediction system** using the **Rain in Australia dataset**.  
The objective is to predict whether it will rain the following day by leveraging historical weather observations and applying supervised learning techniques.

The project focuses on **data preprocessing, feature engineering, and model optimization** to improve prediction accuracy.

---

## ✨ Features

- **📊 Binary Rainfall Prediction**  
  Predicts next-day rainfall (`RainTomorrow`) based on historical meteorological data.

- **🧹 Comprehensive Data Preprocessing**  
  Handles missing values, categorical encoding, and feature scaling to ensure high-quality model inputs.

- **🌲 Ensemble Learning with Random Forest**  
  Uses **Random Forest** to capture non-linear relationships in weather patterns.

- **📈 Performance Optimization**  
  Achieved **88% prediction accuracy** through iterative tuning and feature selection.

## 🔍 How It Works

### 1️⃣ Data Exploration & Preprocessing
- Performed **exploratory data analysis (EDA)** to understand feature distributions and correlations.
- Cleaned the dataset by handling missing values and removing inconsistencies.
- Encoded categorical variables and scaled numerical features.

---

### 2️⃣ Model Training
- Trained a **Random Forest classifier** to model complex relationships between weather attributes.
- Optimized hyperparameters to balance bias and variance.

---

### 3️⃣ Evaluation
- Evaluated model performance using accuracy and classification metrics.
- Achieved **88% accuracy** on validation data.
